# Kanban Project Manager

A single-board Kanban project management web application built with Next.js and React.

## Features

- Single board view with 5 customizable columns
- Inline column title editing
- Add new cards with title and details
- Delete existing cards
- Drag and drop cards within and across columns
- Initial sample data pre-populated

## Color Palette

- Dark Navy: `#032147` (Headings)
- Blue Primary: `#209dd7` (Key sections & links)
- Purple Secondary: `#753991` (Action buttons)
- Accent Yellow: `#ecad0a` (Highlights & accents)
- Gray Text: `#888888` (Labels & supporting text)

## Getting Started

### Development

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Testing

```bash
cd frontend
npm test
npm run test:e2e
```
